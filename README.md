# Premier Leaguers ⚽

**Premier Leaguers** is a web project about the English Premier League, created as a **university project**.  
The website provides news, media, league tables, fixtures, results, statistics, and fantasy-related content in a clean and simple UI.

---

## 🚀 Technologies Used

- **HTML5** – page structure
- **CSS3** – styling and layout
- **JavaScript (Vanilla)** – simple interactivity (like random player images)

---

## 📌 Features

- Responsive navigation bar
- Latest Premier League news with external links
- Media section (videos & highlights)
- League table preview with club rankings
- Fantasy Premier League news

### Pages Included

- Home
- Fixtures
- Results
- Tables
- Statistics
- Awards
- Login / Signup

---

## 🎓 Project Info

- Created by **college students**
- Part of a **Faculty of Business – Alexandria University** project
- Built using only **pure front-end technologies** (no frameworks)

---

## 📎 External Libraries & Resources

- **Font Awesome** – icons
- **Google Fonts (Cairo)**
